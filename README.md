# ICSI 418Y - Programming Assignment 3
**Name:** Benny Wang

## Description
A full-stack Login and Signup application. The frontend is built with React and communicates with an Express/Node.js backend. User data is stored in a MongoDB database.

## How to Run
You need two terminals open at the same time.

**Terminal 1 (Backend):**
1. cd server
2. npm install
3. npm run dev

**Terminal 2 (Frontend):**
1. cd client
2. npm install
3. npm run dev

Then open http://localhost:5173 in your browser.
